# BuildSafe — Claude Code handoff package

## Quick start
1. Unzip this folder → open a terminal inside it
2. Run: claude
3. Say: "Read CLAUDE.md and everything in /docs, then confirm the build order back to me before writing code."

## What's inside
- CLAUDE.md            → project brief (Claude Code auto-reads this every session)
- /site                → working frontend prototype (open site/index.html in a browser to demo all 6 pages)
- /docs                → Master Plan (features+legal+money) · Competitive Analysis · Website Teardown · design methodology
- /archive             → alternative single-page marketing landing (fintech style), keep for reference

## Demo the prototype
Open site/index.html → click through: onboarding (3 roles), tradie app (apply to jobs, Available Now, edit profile), builder app (post a job — it publishes live), customer app (deposit-safety check: try "Harbourline" vs "Redgum"), public profile (write a review).
